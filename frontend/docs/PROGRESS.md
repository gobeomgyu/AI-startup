## 실행 결과

- `npm.cmd run check`: 통과. ESLint, Prettier, TypeScript, Vitest 1개 테스트 통과.
- `npm.cmd run build`: 통과. `/`, `/tasks`, `/tasks/[id]`, `/settings`, API 프록시 빌드 확인.
- 분리된 SQLite DB(`.local/integration.sqlite3`)를 사용하는 실제 FastAPI를 8001 포트에 실행하고, 최종 Next.js 빌드를 3001 포트에 실행함.
- `node scripts/integration.mjs`: 통과. 프런트엔드 프록시를 통해 목록, 담당자 조회·할당, 생성·상세·수정, 설명·담당자·마감일 `null` 초기화, 태그 교체·전체 제거, 상태 변경, 422, 삭제, 404 확인. 테스트 데이터 정리.
- 백엔드를 중단한 뒤 프록시 `GET /api/v1/tasks`가 503과 재시도 메시지를 반환하고, 재실행 후 200으로 복구되는 것을 확인.
- 의존성 설치 중 `prepare`가 Git 소유권 차이로 실패해 설치를 `--ignore-scripts`로 완료한 뒤 훅 스크립트를 수정하고 직접 실행해 확인함.

## 미검증 범위와 다음 작업

- `docs/TEST_CASE.md`의 **M-01~M-30 브라우저 수동 시나리오는 미실행**. 컴퓨터 사용 도구의 브라우저 목록이 비어 있고 `iab` 브라우저도 사용할 수 없어서 실제 클릭, 모바일 화면, 키보드, 테마 지속성을 브라우저에서 확인할 수 없었다. 위 API 통합 결과를 수동 시나리오 통과로 간주하지 않는다.
- 브라우저가 제공되면 분리된 테스트 DB로 프런트엔드와 백엔드를 실행하고 M-01~M-30을 순서대로 수행한다. 화면 크기 390px과 Tab/Enter/Space 조작, 백엔드 중단·복구 시나리오를 포함한다.
