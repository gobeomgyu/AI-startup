## Brand & Style

The design system is engineered for modern high-velocity SaaS workflows where information density, precision, and cognitive ease are paramount. Drawing inspiration from precision productivity tools like Linear, Raycast, and Notion, the visual identity pairs absolute utilitarian functionalism with refined visual craft.

### Emotional Response & Personality
- **Focused & Calm:** Interfaces minimize visual noise to induce flow state, prioritizing user content and structured tasks above decorative elements.
- **Instrument-Grade Precision:** Every boundary, spacing unit, and font metrics feel calibrated like a surgical instrument or pro developer terminal.
- **Authoritative & Crisp:** Deep slate tones paired with an electric indigo accent and energetic amber highlights establish confidence, technological excellence, and deliberate action.

### Design Movement: Modern Precision Minimalist
The aesthetic synthesizes modern technical minimalism with subtle translucent glass accents and micro-fine hairpins. Surfaces rely on structural 1px borders, subtle surface luminosity shifts, and restrained diffusion shadows rather than loud structural shapes.

## Colors

The color architecture is built for dense workspaces, engineered natively with a deep dark mode baseline that dramatically mitigates eye fatigue during sustained screen time, alongside a clean light mode counterpart.

### Neutral System
- **Slate Canvas Base (`#0B0F19` to `#0F172A`):** The foundational substrate contains cool blue-slate undertones, preventing pure-black OLED smearing while giving ambient depth.
- **Surface Elevation Steps:** 
  - Substrate / Canvas: `#090D16`
  - Layer 1 (Sidebar / Pane): `#0F172A`
  - Layer 2 (Active Cards / Panels): `#1E293B`
  - Layer 3 (Hover States / Modals / Popovers): `#334155`
- **Text & Foreground Hierarchy:** 
  - Primary Content: `#F8FAFC` (High-contrast Slate 50)
  - Secondary / Supporting: `#94A3B8` (Slate 400)
  - Muted / Placeholder: `#64748B` (Slate 500)
  - Hairline Borders: `#1E293B` on dark, with `#334155` for high-focus boundaries.

### Accents & Status Palette
- **Primary Electric Indigo (`#6366F1` / Hover `#4F46E5`):** Reserved for primary calls to action, focus rings, selected table rows, active tab indicators, and live execution triggers.
- **Secondary Warm Amber (`#E88C51`):** Applied to telemetry metrics, informational badges, and active filters.
- **Semantic Accents:**
  - **Success (Emerald `#10B981`):** Operational states, completed issues, clean CI builds.
  - **Warning (Amber `#F59E0B`):** Blocked tasks, impending limits, high-priority triages.
  - **Critical (Rose `#F43F5E`):** Destructive actions, system outages, overdue deadlines.

## Typography

The typographic hierarchy relies on Inter for universal legibility, optimal vertical metrics, and distinct geometric glyphs across dense screen layouts. JetBrains Mono is paired for monospaced inline values, timestamp badges, and keyboard triggers.

### Principles & Features
- **Tabular Figures (`tnum`):** All numerals within data tables, analytics panels, and financial tickers use `font-feature-settings: "tnum" 1` to ensure vertical alignment across dynamic updates.
- **Micro-Scale Legibility:** Body small (12px) and label small (11px) retain higher relative x-heights and slight positive tracking (`+0.04em`) to maintain fast scanning speeds across meta tags, issue counts, and status pills.
- **Strict Vertical Cadence:** All line-heights are tied to increments of 4px to maintain an invariant baseline grid.

## Layout & Spacing

The layout embraces an adaptive fluid-grid combined with fixed utility rails designed for command-driven desktop productivity.

### Structural Shell & Grids
- **Left Navigation Rail:** Fixed at 240px (collapsible to a 56px icon rail).
- **Secondary Context Pane:** Fixed at 320px for detail inspection, timeline events, or inspector panels.
- **Main Canvas:** Fluid container stretching across remaining screen real estate with a maximum content clamp of 1440px for single-column views, or 100% width for dense data grids.
- **Breakpoints:**
  - `Desktop XL` (≥1440px): Full 3-pane workstation view.
  - `Desktop / Laptop` (1024px – 1439px): Dual-pane with sheet drawers.
  - `Tablet` (768px – 1023px): Collapsed navigation drawer, full-width canvas, 16px margins.
  - `Mobile` (<768px): Single-column reflow, bottom sheet navigation, contextual toolbars anchored to the viewport base.

### Spatial Rhythm
- Internal component spacing uses tight 4px and 8px units (`space-xs`, `space-sm`) to maximize density without creating visual clutter.
- Section paddings utilize `space-xl` (24px) to create breathing room between discrete task domains.

## Elevation & Depth

Visual hierarchy is constructed through structural surface stacking, fine 1px borders, and translucent glassmorphic layering rather than heavy drop shadows.

### Elevation Architecture
1. **Base Floor (Z-0):** `#090D16` – Canvas background; zero shadow.
2. **Structural Panels (Z-1):** `#0F172A` with a 1px border (`rgba(255, 255, 255, 0.08)` or `#1E293B`).
3. **Elevated Cards & Popovers (Z-2):** `#1E293B` backed by a diffuse ambient shadow: `box-shadow: 0 4px 20px -2px rgba(0, 0, 0, 0.45)`.
4. **Command Bars & Modals (Z-3):** Translucent backdrop blur (`backdrop-filter: blur(16px); background: rgba(15, 23, 42, 0.85);`) with a hairline border (`rgba(255, 255, 255, 0.12)`) and deep presence shadow: `box-shadow: 0 16px 48px -8px rgba(0, 0, 0, 0.65)`.

### Border Discipline
Drop shadows are never used without a crisp defining hairline edge. This maintains architectural separation under low display contrasts or varying display calibrations.

## Shapes

The design system embraces a **Soft (Level 1)** shape system, establishing compact precision without aggressive sharp corners.

### Radii Tokens
- **Base Components (`0.25rem` / `4px`):** Checkboxes, tags, badges, input controls, table selection states, and keyboard shortcut chips.
- **Medium Elements (`0.375rem` / `6px`):** Standard buttons, list-item hover pills, dropdown menus, and nested containers.
- **Cards & Modals (`0.5rem` / `8px`):** High-level task cards, settings panels, floating command palettes (Raycast-style), and split panes.
- **Pill Exceptions (`9999px`):** User avatars and active pulsing status dots only. Interactive buttons and chips remain structured rectangular forms with soft corners.

## Components

### Buttons
- **Primary:** Solid Electric Indigo (`#6366F1`), white text, crisp 1px inset highlight (`box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.2)`), hover shifts to `#4F46E5`.
- **Secondary:** Surface `#1E293B`, border 1px solid `rgba(255, 255, 255, 0.08)`, text `#F8FAFC`. Hover shifts to `#334155`.
- **Ghost / Icon Action:** Transparent background, text `#94A3B8`, hover background `rgba(255, 255, 255, 0.05)`, hover text `#F8FAFC`. Compact padding (6px for 28px hit target).

### Inputs & Search Bars
- Standard height: 32px (compact) and 40px (default).
- Background `#0F172A`, 1px border `#334155`.
- Active focus state: Border color transitions to `#6366F1` with an outer focus halo `0 0 0 2px rgba(99, 102, 241, 0.25)`.
- Includes trailing keyboard shortcut tokens (`⌘K`) aligned right.

### Keyboard Shortcut Chips (Kbd)
- Monospaced typography via JetBrains Mono (`code-sm`).
- Height: 20px, minimum width: 20px.
- Background `#1E293B`, subtle border 1px solid `#334155`, text `#94A3B8`, border-radius 3px.

### Badge & Status Tags
- Compact height: 20px, font size 11px (`label-sm`), uppercase with +0.04em tracking.
- Subtle background tint combined with matching solid text and a 1px border at 20% opacity.
- Optional 6px circular dot indicator preceding the label text.

### Interactive Data Tables
- Row height: 36px (compact) to 44px (spacious).
- Subtle 1px bottom border `#1E293B`.
- Row hover: `#1E293B` at 50% opacity.
- Row selected: Background `rgba(99, 102, 241, 0.08)` with a 2px left border accent in `#6366F1`.
- Numbers formatted with `font-feature-settings: "tnum" 1`.

### Command Palette (Spotlight / Raycast Pattern)
- Fixed center-top screen overlay, max-width 640px.
- Translucent backdrop blur panel (`rgba(15, 23, 42, 0.90)`), 8px border-radius, hairline border.
- Integrated quick-search input with instant arrow-key row navigation and pinned command actions.
